# Contributing
- Branch from `main`: `feat/<id>-<name>`, `fix/<id>-<name>`.
- Conventional Commits. One logical change per PR.
- `pnpm check` must pass locally. CI must be green.
- Fill the PR template (what, how tested, screenshots at 390/768/1024/1440, migrations, risks, rollback).
- One human reviewer (tech lead) approves. Agents prepare, humans merge.
