# Security
Report: security@octavolab.com (replace with the group address). Do not open public issues for vulnerabilities.

Implemented today (template v0.5.0): Argon2id passwords; signed short-lived sessions (HMAC-SHA256, httpOnly, Secure in production, SameSite=Strict) rotated after half their life, with a 12-hour absolute lifetime from sign-in (tested); role checks and tenant-scoped reads (another tenant's order returns 404, tested; orders are readable by staff roles only, customer self-service is roadmap); login rate limit 5/min per account from any IP, with proxy trust limited to one hop (tested with rotating X-Forwarded-For); constant-work login for unknown emails; zod validation at the edge with 4xx on validation errors; Stripe webhook signature check with 300 s tolerance, event record, amount and currency check and state change in one transaction with rollback on failure (tested); fake payments webhook closed when NODE_ENV=production; live-mode guard; parameterized queries (Prisma); helmet CSP + HSTS; CORS allowlist; global rate limit; request id and redacted logs; secrets only in environment; gitleaks, semgrep, osv-scanner and trivy in CI.
Roadmap before any production deploy (Módulo C 6.2): 2FA for admins and owners, server-side session revocation list in PostgreSQL, ZAP baseline nightly against staging (job wired, needs STAGING_URL), restore test, IAM role per project (OIDC) with MFA, OWASP ASVS L2 manual checklist signed.
